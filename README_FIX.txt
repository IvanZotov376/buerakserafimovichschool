Как запустить:

1. Установите зависимости:
   pip install -r requirements.txt

2. Запустите сервер:
   python server.py

3. Откройте личный кабинет через сервер:
   http://127.0.0.1:5000/

Если открываете с другого устройства в той же сети, используйте IP компьютера с сервером:
   http://IP_КОМПЬЮТЕРА:5000/
